## Retrospective

- **最初の失敗 → 最終解**: 初版はコマンド文字列全体に正規表現を当てて操作と対象 repo を判定していたため、引用符・global option・複合コマンドという普通の書き方で検査が漏れた → shell と同じ規則で引数に分解し、操作ごとに判定する形にした
- **事前知識化**: コマンドを検査する hook は、文字列への正規表現ではなく引数の分解から始める。検査できなかったときは止める（PreToolUse は exit 2 以外の失敗を通してしまう）
