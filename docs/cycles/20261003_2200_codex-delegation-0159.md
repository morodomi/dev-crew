## Retrospective

- **最初の失敗 → 最終解**: 置換前の orchestrate の呼び出しは、`--full-auto` を外しても `resume` の後ろにフラグを置いているため rc=2 で止まる形だった。テストが「`--full-auto` があること」を pin していたので、壊れた呼び出しが緑のまま残っていた → テストを「今の CLI で動く形」の契約に置き換えた
- **事前知識化**: 外部 CLI の呼び出し形を pin するテストは、フラグの有無ではなく「実測した動く形」で書く。CLI の更新時は `--help` と最小実行で形を確かめ直す
